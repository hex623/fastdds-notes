关键数据结构

GUID

struct GUID_t {
    GuidPrefix_t guidPrefix;  // 12 bytes
    EntityId_t entityId;      // 4 bytes
};

// 示例: 01.0f.da.70.f5.ea.d7.9b.00.00.00.00|0.0.1.4
//       └──────── GUID Prefix ────────┘ |Entity|

GUID Prefix 组成 (12 bytes)

字段 大小 说明
Vendor ID 2 bytes 厂商标识 (0x010f = eProsima)
Domain ID 2 bytes 域标识
Instance ID 8 bytes MAC/时间戳/随机数

Entity ID 组成 (4 bytes)

字段 大小 说明
Entity Type 3 bytes 实体类型 (Participant/Writer/Reader)
Instance Num 1 byte 实例编号

唯一性保证

  • MAC + 时间戳 + 随机数 + 冲突检测
  • 即使同一台机器同时启动多个 Participant 也能区分

CacheChange

struct CacheChange_t {
    ChangeKind_t kind;              // ALIVE, DISPOSE, etc.
    GUID_t writerGUID;              // 写入者 GUID
    SequenceNumber_t sequenceNumber; // 序列号
    SerializedPayload_t serializedPayload; // 序列化数据
    Time_t sourceTimestamp;         // 时间戳
    InstanceHandle_t instanceHandle; // 实例句柄
};

SequenceNumber

struct SequenceNumber_t {
    int32_t high;   // 高32位
    uint32_t low;   // 低32位
};
// 支持 2^64 个序列号，实际使用 low 部分
