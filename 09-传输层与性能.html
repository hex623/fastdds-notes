09 - 传输层与性能

来源: 2026-03-03 笔记
整理时间: 2026-03-17

传输层类型

Fast-DDS 支持多种传输方式：

传输 协议 适用场景
UDPv4 UDP IPv4 局域网，默认
UDPv6 UDP IPv6 IPv6 网络
TCPv4 TCP IPv4 NAT 穿透、跨网段
SHM 共享内存 同机进程间，最快

UDPv4 传输

特点

  • 无连接，开销小
  • 支持组播（发现协议依赖）
  • 局域网首选

配置

DomainParticipantQos qos;

// 添加 UDPv4 传输
auto udp_transport = std::make_shared<UDPv4TransportDescriptor>();
udp_transport->sendBufferSize = 1048576;  // 1MB 发送缓冲
udp_transport->receiveBufferSize = 1048576;  // 1MB 接收缓冲
qos.transport().user_transports.push_back(udp_transport);
qos.transport().use_builtin_transports = false;

TCPv4 传输

特点

  • 面向连接，可靠性由 TCP 保证
  • 支持 NAT 穿透
  • 适合跨网段、广域网

配置

DomainParticipantQos qos;

// 添加 TCPv4 传输
auto tcp_transport = std::make_shared<TCPv4TransportDescriptor>();
tcp_transport->add_listener_port(5100);
tcp_transport->sendBufferSize = 1048576;
tcp_transport->receiveBufferSize = 1048576;
qos.transport().user_transports.push_back(tcp_transport);
qos.transport().use_builtin_transports = false;

// 配置 WAN 地址（用于 NAT 穿透）
Locator_t wan_locator;
wan_locator.kind = LOCATOR_KIND_TCPv4;
wan_locator.port = 5100;
IPLocator::setIPv4(wan_locator, "203.0.113.1");
qos.wire_protocol().builtin.metatrafficUnicastLocatorList.push_back(wan_locator);

SHM 共享内存

特点

  • 最快传输：零拷贝，无网络开销
  • 仅支持同机进程间通信
  • 自动回退到 UDP（如果 SHM 失败）

配置

DomainParticipantQos qos;

// 添加 SHM 传输
auto shm_transport = std::make_shared<SharedMemTransportDescriptor>();
shm_transport->segment_size(2 * 1024 * 1024);  // 2MB 段大小
shm_transport->max_message_size(1 * 1024 * 1024);  // 1MB 最大消息
qos.transport().user_transports.push_back(shm_transport);

性能对比

传输 延迟 吞吐量 CPU
SHM ~1μs 最高 最低
UDP ~50μs 高 低
TCP ~100μs 中 中

性能优化策略

1. 零拷贝传输

// 使用 SHM 共享内存实现零拷贝
auto shm_transport = std::make_shared<SharedMemTransportDescriptor>();
shm_transport->segment_size(10 * 1024 * 1024);  // 10MB
qos.transport().user_transports.push_back(shm_transport);

2. 批处理（Batching）

// 启用异步写入批处理
DataWriterQos writer_qos;
writer_qos.publish_mode().kind = ASYNCHRONOUS_PUBLISH_MODE;

// 配置批处理参数
writer_qos.batch().enable = true;
writer_qos.batch().max_data_bytes = 64000;  // 每批最大 64KB
writer_qos.batch().max_samples = 100;        // 每批最多 100 样本
writer_qos.batch().max_send_batched_period = {0, 100000000};  // 100ms 超时

3. 数据分片

// 大数据自动分片传输
DataWriterQos writer_qos;
writer_qos.history().depth = 10;

// 启用分片
writer_qos.reliable_writer_qos().disable_positive_acks = false;

4. QoS 调优

// 最佳吞吐量配置
DataWriterQos writer_qos;
writer_qos.reliability().kind = BEST_EFFORT_RELIABILITY_QOS;
writer_qos.history().kind = KEEP_LAST_HISTORY_QOS;
writer_qos.history().depth = 1;  // 只保留最新

// 最佳延迟配置
DataWriterQos writer_qos;
writer_qos.reliability().kind = RELIABLE_RELIABILITY_QOS;
writer_qos.history().kind = KEEP_ALL_HISTORY_QOS;

性能测试方法

吞吐量测试

# 使用 Fast-DDS 自带性能测试工具
./DDSPerfTest --data_size=1024 --sample_count=10000

延迟测试

# 往返延迟测试
./DDSLatencyTest --data_size=256 --sample_count=1000

关键指标

指标 测量方法 目标
吞吐量 samples/second >100K msg/s
延迟 round-trip time <100μs (SHM)
CPU 占用 top/ps <20%
内存占用 RSS 监控增长
